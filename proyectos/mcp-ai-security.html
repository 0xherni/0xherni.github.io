MCP / AI Security

Investigación en seguridad de protocolos MCP e IA, con foco en autenticación JWT y gestión segura de secrets.

MCP JWT Auth Secrets Mgmt Research

01 / Motivación

Texto de ejemplo — por qué investigaste la superficie de ataque de servidores MCP: adopción creciente, falta de estándares de seguridad maduros, riesgo de exposición de secrets en integraciones IA.

02 / Superficie de ataque

Texto de ejemplo — vectores analizados: autenticación entre cliente/servidor MCP, manejo de tokens JWT, exposición de herramientas (tools) sin control de acceso, inyección de prompts a través de contenido no confiable.

EDITAR: diagrama de superficie de ataque

03 / Hallazgos

Texto de ejemplo — hallazgos concretos: malas prácticas de gestión de secrets, tokens JWT sin expiración o sin validación de audiencia, falta de scoping de permisos por herramienta.

# Ejemplo: validación de JWT con verificación de audiencia y expiración
import jwt

def verify_token(token: str):
    payload = jwt.decode(
        token,
        key=PUBLIC_KEY,
        algorithms=["RS256"],
        audience="mcp-server",
    )
    return payload

04 / Recomendaciones

Texto de ejemplo — recomendaciones de hardening: rotación de secrets, least privilege por herramienta expuesta, logging y auditoría de llamadas a tools, validación estricta de entrada para mitigar prompt injection.
